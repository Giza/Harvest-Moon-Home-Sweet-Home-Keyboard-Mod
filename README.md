## English

A lightweight mod that adds full **Keyboard & Mouse** support to **Harvest Moon: Home Sweet Home Special Edition** (which natively only supports controllers/gamepads).

### 🎮 Default Controls

| Key | Action | Gamepad Equivalent |
| :--- | :--- | :--- |
| `W`, `A`, `S`, `D` / `Arrow Keys` | Character Movement | Left Stick |
| `I`, `K`, `J`, `L` | D-Pad Navigation | D-Pad (Up, Down, Left, Right) |
| `Space` / `Enter` / `LMB` (Left Click) | Primary Action / Confirm | `A` |
| `F` | Secondary Action | `X` |
| `R` | Action | `Y` |
| `Tab` | Open Menu / Pause | `Menu` / `Start` |
| `Ctrl` / `Tab` | Previous / Next Tab in menus | `LB` / `RB` |

### 📦 Installation

1. Download the latest release from the [Releases](../../releases) tab.
2. Extract the files directly into the root folder of the installed game (where the main executable `.exe` is located).
3. Launch the game as usual.

### ⚙️ Compatibility

* Tested on **Harvest Moon: Home Sweet Home Special Edition** (PC).

## Русский

Мод добавляет полноценную поддержку управления с **клавиатуры и мыши** в игру **Harvest Moon: Home Sweet Home Special Edition**, которая изначально работает только с геймпадами.

### 🎮 Раскладка управления

| Клавиша | Действие | Аналог на геймпаде |
| :--- | :--- | :--- |
| `W`, `A`, `S`, `D` / `Стрелки` | Передвижение | Левый стик (Left Stick) |
| `I`, `K`, `J`, `L` | Навигация D-Pad | Крестовина (D-Pad) |
| `Пробел` / `Enter` / `ЛКМ` (Левая кнопка) | Основное действие / Подтверждение | `A` |
| `F` | Взаимодействие | `X` |
| `R` | Действие | `Y` |
| `Tab` | Открыть меню / Пауза | `Menu` / `Start` |
| `Ctrl` / `Tab` | Переключение вкладок меню | `LB` / `RB` |

### 📦 Установка

1. Скачайте архив из раздела [Releases](../../releases).
2. Распакуйте файлы в корневую папку с установленной игрой (туда, где лежит исполняемый файл `.exe`).
3. Запустите игру как обычно.

### ⚙️ Совместимость

* Протестировано на версии **Harvest Moon: Home Sweet Home Special Edition** (PC).
